## 1. Instalar o Node.js

Baixe e instale o **Node.js v24.19.0** pelo instalador oficial:

https://nodejs.org/dist/v24.19.0/node-v24.19.0-x64.msi

Durante a instalação, **habilite a opção relacionada ao Chocolatey**, quando apresentada pelo instalador.

## 2. Instalar o Git Flow

Após concluir a instalação do Node.js, abra o **Prompt de Comando (CMD) ou PowerShell como Administrador**.

Execute o seguinte comando:

```bash
choco install gitflow-avh
```

Confirme a instalação quando solicitado.

Ao finalizar, o **Git Flow** estará disponível para uso no terminal.
